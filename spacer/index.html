Spacer US host pages

Five new host child pages built on the rent-my-driveway template. This is a build reference for devs, not the live site.

Content sources

  • Rent my garage
  • Rent my space for storage
  • Rent my land for RV and boat storage
  • Rent my parking lot
  • Rent my apartment parking space

Body copy is verbatim from each doc. Doc links that went through Google's redirect wrapper now point straight at their targets.

What changes per page

  • Hero: the H1 is the doc title. The subheading is the doc's opening line. Unlike driveway, there is no "Earn up to $X/month" figure, because the docs say earnings are not guaranteed. The CTA is unchanged ("List My Parking Spot" → /rent-out-my-space).
  • Hero photo: each page has its own .sec-hero background, set by the body class in shared/prototype.css. A light left-side fade keeps the dark text readable. Below 992px it becomes a full wash.
    • Garage: Unsplash, @sijmen89
    • Storage: Spacer's garage-near-me-desktop-hero.jpg
    • RV and boat: Unsplash, @brodus_k
    • Parking lot: Spacer's business/property-investor/hero-background.webp
    • Apartment: Spacer's business/small-business/hero-background.webp
  • Intro (.sec-details): the doc paragraphs before the first H2.
  • Body (.sec-landing-details): everything from the first H2 to the end. FAQs render as H3 plus paragraphs inside the same text block, with no accordion.
  • New in the body block: h2/h3, ul/ol and one table (parking lot page only). Driveway never needed these. They reuse existing utility classes, and the few extra rules are in shared/prototype.css.
  • Head: <title> is "H1 | Spacer". The meta description comes from the opening line. Canonical points to the production URL.
  • Schema (optional): each page carries FAQPage JSON-LD built from its FAQ section.

What stays identical

Announcement bar, nav, renter testimonials, city grid, Popular Areas, Why Host on Spacer, the commuters map, One Tree Planted and the footer. The markup comes from the live driveway page, and shared/spacerus.css is the live compiled stylesheet.

Prototype vs production

  • The Stimulus controllers (campaign-banner, nav-spus, landing-page) are stood in for by shared/script.js. Production should keep its own controllers.
  • Left out: the chat widget, the 10% off popup, analytics and ad trackers.
  • Nav and footer links point to live spacer.com.

Flags for the template owner

  • Under "Why Host on Spacer?", the descriptions for "It's FREE and easy to list", "Start Earning Quickly" and "You set the rules" are written for renters, not hosts. They were left as they are live.
  • On live, all three testimonial images have alt="Rachel, Boston". Each one is corrected here.
  • When the pages ship, add them to the footer's host links next to "Rent My Driveway".
